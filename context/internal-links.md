# Internal Links

Optional advanced setup. If you are just getting started with SEO, you can leave this mostly blank and come back later.

The live sitemaps (`https://connect.panosia.com/sitemap-posts.xml`, `sitemap-static.xml`) are the source of truth for real slugs and what's actually published — see `docs/article-writing.md`'s Live Content Discovery section. Use this file only for durable linking guidance the sitemap can't tell you (which pages matter most, what anchor text to use, when a link is appropriate) — not as a slug list, since it will drift.

List important pages and when they should be linked.
